# Hologram Post-Sales GTM Engineering Take-Home Exercise

Live billing simulator: https://shayzer0.github.io/hologram-post-sales-exercise/

## Overview

This repo is my submission for the Hologram GTM Post-Sales Engineer take-home exercise. It covers the contract-to-billing configuration, billing logic, go-live QA notes, and an interactive billing simulator for a fictional customer, Halcyon Motors (Org ID 90342, Order Form #00002891).

The exercise asks me to take the contract terms from PandaDoc and turn them into clear Salesforce CRM mappings, build out the billing formulas for monthly usage rating, flag any contract ambiguities before go-live, and provide a simple web dashboard a client could use to check their invoice numbers.

## Deliverable summary

* **Section A** (`config/contract_config.md` & `docs/Section_A_Architecture.md`): Extracts the signed PandaDoc contract terms into single-value schemas mapped to custom Salesforce CRM objects (`Account`, `Contract`, `MinSpendSchedule__c`, `OpportunityLineItem`).
* **Section B** (`docs/Section_B_Billing_Logic.md`): Encodes pooled data logic (10 MB/SIM, $0.75/MB overage), Monthly Recurring Charges ($2.43/SIM), and tiered minimum spend commitments. Includes a worked, step-by-step Month 8 invoice calculation ($1,039.50).
* **Section C** (`docs/Section_C_QA_Communication.md`): Flags contract edge cases, drafts an internal escalation memo to Deal Desk regarding mid-month Test Mode conversions, and proposes post-sales process automation.
* **Interactive web simulator** (`docs/index.html`): Client-facing dashboard deployed via GitHub Pages, letting reviewers adjust active SIMs, pooled data usage, and contract months to preview billing totals dynamically.

## Key contract & billing assumptions

While translating the contract and building the rating logic, I made the following assumptions:

1. **Mid-month Test Mode conversions** - When a SIM hits an auto-activation trigger (100 KB data, 10 outbound SMS, or 90 days), it converts to `ACTIVE` status and incurs the full $2.43 Monthly Recurring Charge for that billing cycle. Mid-month prorating is flagged as a QA item pending Deal Desk alignment.
2. **Hardware spending exclusion** - Physical G3-F SIM card purchases ($4.50/SIM) are tracked under `OpportunityLineItem` and are explicitly excluded from qualifying monthly spend toward the minimum spend floor.
3. **Un-migrated G1 SIM usage** - Any spend generated by legacy G1 SIMs that fail automatic migration to G3 profiles still applies toward Halcyon Motors's dynamic monthly spend floor.
4. **Setup lag & start date** - Billing logic strictly enforces the August 1, 2026 contract start date for term and minimum spend tier tracking, despite the noted 4-week dashboard setup delay.
